# K-Salary 1.0.6

Android release: **versionName 1.0.6 / versionCode 7**. Package: `com.koreasalary.calculator`.
Commits: day-edit action row `7bbfaba`, calendar badge colors `bd55e3f`.

## Changes

- Day-edit dialog action row: "Сохранить" stays on one complete centered line at any width (font floor 12 sp), "Очистить день" may wrap into two horizontally centered lines, "Отмена" stays centered. Three-action state weights 1.1 / 0.9 / 1.2, two-action state stays 1 / 1. Conditional visibility, test tags, callbacks, scrolling and dialog sizing are unchanged.
- Calendar worked-hours badges follow the saved work categories: premium work (explicit holiday hours, legacy decoded holiday work, and combined 1.5× hours entered on Saturday, Sunday, a manually marked paid holiday or weekly-rest day) is ruby; night premiums stay purple; ordinary 1.5× overtime is orange; base work is green on any day. Paid-day flags keep their status styling only for days without physical work.
- Preserved: physical-hour totals, badge label formatting, date-number colors, red/blue cell borders, empty-day appearance, all 12 localizations, pay calculations, the eight-hour base-hours limit and the Room/storage schema.

- Gradle: offline unit tests, debug and android-test assembly successful for both fixes.
- Before/after calendar evidence (320×568 dp, light and dark) under `docs/verification/premium-badge-20261107/`; action-row evidence under `docs/verification/action-row-20261107/`.
